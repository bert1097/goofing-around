# goofing-around: notes for Claude Code

Personal side projects (see `README.md`). Nothing here is Brett AI work.

## Sessions
- Use one Claude Code session per project or task, and archive it at a stopping point.
- Session titles follow `<Status> · <topic> · <PRs>`, where the status is Working, Needs you, Review, Done or Failed and the PRs are the numbers of the PRs the session made. If you retitle your session, keep that format; a cleanup session keeps the status part up to date.
- Before you finish, push your branch and open a PR, so nothing is lost when the session is archived.
